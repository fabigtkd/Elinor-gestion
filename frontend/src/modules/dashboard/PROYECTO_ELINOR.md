# ELINOR GESTIÓN

## Objetivo

Crear un sistema de gestión propio para Elinor Pollos.

La prioridad no es tener muchas funciones, sino ahorrar tiempo, controlar el negocio y aumentar la rentabilidad.

---

# Filosofía del proyecto

Cada función debe cumplir al menos uno de estos objetivos:

- Ahorrar tiempo.
- Ahorrar dinero.
- Aumentar la rentabilidad.
- Brindar información para tomar mejores decisiones.

Si una función no cumple alguno de esos objetivos, no forma parte de la Versión 1.

---

# Reglas del proyecto

## Regla N.º 1

Siempre reemplazamos archivos completos.

Nunca modificamos pequeños fragmentos.

---

## Regla N.º 2

Cada bloque debe terminar funcionando antes de comenzar el siguiente.

---

## Regla N.º 3

Cada bloque importante termina con:

- Prueba
- Commit
- Actualización de la documentación

- ¿Cuánto vendí hoy?
- ¿Cuánto dinero tengo en caja?
- ¿Qué tengo que comprar?
- ¿Qué productos debo producir?
- ¿Cuál es mi rentabilidad?
- ¿Qué precio debería cobrar?
